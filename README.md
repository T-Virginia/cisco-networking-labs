## 🚀 Come aprire i file `.pkt`
1. Scarica e installa **Cisco Packet Tracer** (disponibile gratuitamente registrandosi su [Cisco Networking Academy](https://www.netacad.com/)).
2. Clona la repository o scarica il singolo file `.pkt` dalla cartella del laboratorio.
3. Apri il file direttamente in Packet Tracer per esplorare la topologia e testare la rete.
